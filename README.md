# Unsubscribe study repository


This repository contains source code for the entire study.
At this point it includes config we used for Postfix, script to automatically unsubscribe from newsletters.

It is a work in progress, so no real automation or code cleanup. Only half working scripts, so if it doesn't work - it works on our machines.
The work is in early stages, so no decisions on releasing dataset or final release version of our toolkit was made. Stay tuned so to speak.
